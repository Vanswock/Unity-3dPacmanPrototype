# Unity 3dPacman Prototype

A 3d concept for pacman was made in Unity as part of my journey of recreating classic games.

## Play Online

Play here: [https://3dpacman-mu.vercel.app/](https://3dpacman-mu.vercel.app/)


## Features

- 2d to 3d maze genrator
- Different Ghost AI
- Multiple States based on a timer
- Pause menu
- WebGL build

## Built With

- Unity 6
- C#
